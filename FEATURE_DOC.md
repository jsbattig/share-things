# ShareThings: System Capabilities

ShareThings is a secure, real-time content sharing application designed to facilitate easy and private exchange of information between users in a shared session.

## Key Features:

### 1. Secure Session Management
• **Create or Join Sessions**: Users can easily create a new sharing session or join an existing one by providing a unique Session ID, their name, and a secret Passphrase.
• **Random ID/Passphrase Generation**: For convenience and enhanced security, the system can automatically generate random, easy-to-use Session IDs and passphrases.
• **End-to-End Encryption**: All content shared within a session is encrypted using your chosen passphrase before it leaves your device. This ensures that only participants with the correct passphrase can view the content, and the server never has access to your unencrypted data.
• **Real-time User List**: See who else is currently connected to your session, allowing for collaborative sharing.
• **Session Persistence & Reconnection**: The system attempts to automatically reconnect you to your session if your connection is temporarily lost, ensuring a seamless experience.
• **Session Expiration**: Sessions are designed to expire after a period of inactivity to enhance security and manage resources.

### 2. Versatile Content Sharing
• **Share Text**: Instantly share text messages, code snippets, or any written information with all session participants.
• **Share Files**: Upload and share various types of files, including images, documents, and other file formats.
• **Large File Support**: The system efficiently handles large files by breaking them into smaller encrypted chunks, ensuring reliable transfer even for big documents or high-resolution images.
• **Clipboard Integration**: Quickly paste text or images directly from your clipboard into the session.
• **Drag-and-Drop Sharing**: Conveniently share files by simply dragging them into the application interface.
• **Upload Progress**: Monitor the progress of your file uploads with a clear progress indicator.

### 3. Content Management & Organization
• **Content List**: All shared content is displayed in a clear, organized list within the session.
• **Sorting Options**: Easily sort shared content by newest or oldest first, helping you navigate through the history of shared items.
• **Content Pinning**: Pin important content to the top of the list for quick access, ensuring it's always visible regardless of when it was shared.
• **Load More Content**: For sessions with a large amount of shared content, you can load older items as needed, preventing the interface from becoming cluttered.
• **Clear All Content**: Session hosts have the option to clear all shared content from the session, providing a way to reset or clean up the sharing space. This action requires confirmation to prevent accidental data loss.
